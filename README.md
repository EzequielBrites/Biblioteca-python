# 📚 Biblioteca en Python

Este proyecto es un programa de consola en **Python** que simula un sistema de gestión de biblioteca simple.
Permite ingresar títulos, administrar ejemplares, consultar disponibilidad, listar libros agotados y registrar préstamos o devoluciones.

---

## 🚀 Requisitos

* Python 3.10 o superior (recomendado por el uso de `match case`)

---

## ▶️ Ejecución

Clonar el repositorio y ejecutar el archivo principal:

```bash
python biblioteca.py
```

---

## 📖 Funcionalidades

1. Ingresar títulos
2. Ingresar ejemplares
3. Mostrar catálogo
4. Consultar disponibilidad
5. Listar agotados
6. Agregar título
7. Actualizar ejemplares (préstamo/devolución)
8. Salir
